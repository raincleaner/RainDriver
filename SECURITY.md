# Security

If you believe you have found a security vulnerability in Rain Driver, please report it privately to **support@raincleaner.eu**.

Please include the Rain Driver version, the Windows version, the steps to reproduce and any screenshots or error messages. Do not send passwords, licence keys or other personal data.

We read every report and will answer as soon as we can. Please do not post exploit details publicly before we have had a chance to fix the issue.
